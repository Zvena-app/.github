## zvena

A free, open-source workspace for teams: design, docs, projects, calendar and mail in one place.

- **Source code:** [Zvena-app/zvena-oss](https://github.com/Zvena-app/zvena-oss) — GNU AGPL 3.0 (Design: MPL 2.0, a Penpot fork). Run it on your computer in five commands or on your own server.
- **Hosted version:** [zvena.app](https://zvena.app)
- **Security reports:** privately, see [SECURITY.md](https://github.com/Zvena-app/zvena-oss/blob/main/SECURITY.md)
